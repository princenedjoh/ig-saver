# Privacy policy

IG Saver does not collect, store, sell or share any personal data.

- **No servers.** The extension has no backend and makes no requests to anything but instagram.com.
- **What it reads.** On instagram.com it reads the page you're viewing (post and story identifiers) and your existing Instagram session cookie, which the browser sends automatically with the request to Instagram's own API for the media you asked to save.
- **What it stores.** Nothing. There is no analytics, no telemetry and no local storage.
- **Downloads.** Files are saved to your computer through Chrome's downloads API when you click the button.
- **Permissions.** `downloads` (to save files) and access to `www.instagram.com` (to add the buttons and look up media).
